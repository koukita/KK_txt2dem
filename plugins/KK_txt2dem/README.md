# kk_txt2dem

ZIPまたはフォルダー内の `.txt` / `.csv` 標高値データをGeoTIFF標高DEMに変換し、選択した複数のDEMを一つに結合するQGISプラグインです。

## 入力形式

テキストはカンマ区切りで、X座標、Y座標、標高値を指定した列に含めてください。サンプルではX列が2、Y列が3、標高列が4です（1始まりの列番号）。

## 使用方法

1. プラグインを起動します。
2. ZIPファイルが保存されたフォルダーを選択します。
3. 変換する `.txt` をチェックします。
4. 列番号と座標参照系を指定します。
5. グリッドサイズを指定します。単位は指定した座標参照系の座標単位です。0を指定すると入力点間隔から自動推定します。
6. 出力GeoTIFFを指定して「変換開始」を押します。

DEM生成には高速な最近傍補間を使用します。処理速度を優先する設定で、標高点が存在する範囲内ではセルに最も近い標高点が割り当てられます。

## 対応バージョン

- QGIS 3.40以降、QGIS 4.2まで
- Qt5/QGIS 3系とQt6/QGIS 4系の列挙型名の違いを互換処理しています。

## エラー処理

次のエラーについて、画面表示とQGISログパネルへの記録を行います。

| 状況 | 処理 |
| --- | --- |
| フォルダーが存在しない／読取権限がない | エラーメッセージを表示し、処理を中止します。 |
| ZIPが壊れている／暗号化されている／利用量上限を超える | ZIPエラーとして表示し、該当ファイルを選択不可として扱います。 |
| ZIP内に`.txt`がない | リストに表示せず処理対象外とします。 |
| テキストが指定列数未満 | 行番号と不足列を示して中止します。 |
| X・Y・標高の値が数値でない | 行番号と対象列を示して中止します。 |
| 数値の有限性、座標範囲、標高点数が不足 | 入力データエラーとして中止します。 |
| ファイルの文字コードや改行が不正 | UTF-8系として読み込み、読取不能な文字は置換します。 |
| 出力フォルダーがない／書込権限がない／ディスク容量不足 | 書込み可否を事前確認し、中止または例外として表示します。 |
| GDAL/osgeoモジュールまたはOGR VRT処理を利用できない | GDAL依存エラーとして表示します。 |
| CRSが無効またはWKT変換に失敗 | CRSエラーとして表示します。 |
| ラスター生成、投影設定、結合、レイヤ読込みに失敗 | 各処理段階のエラーを表示します。 |
| 作業フォルダーの作成／削除に失敗 | 一時ファイルエラーとして記録し、可能な範囲で後片付けします。 |
| 処理中断 | ユーザーキャンセルとして通知します。 |
| その他の予期しない例外 | 例外内容を表示し、QGISログへ記録します。 |

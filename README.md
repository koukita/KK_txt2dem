# KK_txt2dem

航空レーザで取得したグリッドデータまたはグランドデータ（標高点）の CSV / TXT を、標高 DEM ラスタ（GeoTIFF）に変換する QGIS プラグインです。ZIP ファイル内の CSV / TXT は展開せずに処理できます。

## 主な機能

- 複数の CSV / TXT ファイルまたは ZIP 内のテキストファイルを一括変換
- X・Y・標高の列番号を指定
- 座標参照系を指定
- グリッドサイズを指定、またはデータから自動推定
- グランドデータの Nodata 領域を補間
- 変換した複数の DEM を一つの GeoTIFF に結合
- 完成した GeoTIFF を QGIS の地図レイヤーへ自動追加

## 対応データ

- フォルダー直下の `.csv` または `.txt`
- `.zip` ファイル内に含まれる `.csv` または `.txt`
- 1 行 1 点の形式（例：`X座標,Y座標,標高`）

各データには、3 列以上あり、指定した列に数値が含まれている必要があります。


## 操作方法

### 1. データフォルダーを選択

「CSVファイルまたはZIPファイルのフォルダを選択」欄で、`.csv` / `.txt` / `.zip` を含むフォルダーを指定します。フォルダー内を検索し、変換可能なファイルが一覧に表示されます。

### 2. 変換するファイルを選択

一覧から変換するファイルにチェックを入れます。

| ボタン・表示 | 機能 |
|---|---|
| ファイル一覧のチェックボックス | 個別のファイルを選択または選択解除 |
| **すべて選択** | 一覧で変換可能なファイルをすべて選択 |
| **選択解除** | 一覧のすべてのチェックを解除 |

### 3. 列の指定

データ内の列番号を指定します。列番号は先頭を 1 列目として数えます。

| 項目 | 初期値 | 説明 |
|---|---:|---|
| X列 | 2 | X 座標が記録された列 |
| Y列 | 3 | Y 座標が記録された列 |
| 標高列 | 4 | 標高 Z が記録された列 |

例：`ID,X,Y,Z` の形式では、X 列は `2`、Y 列は `3`、標高列は `4` を指定します。

### 4. グリッドサイズを指定

「グリッドサイズ」で出力 DEM のセル間隔を指定します。

- 数値を指定した場合：指定した座標単位でグリッドを作成
- `0` を指定した場合：座標サンプルからセル間隔を自動推定

グリッドサイズの単位は、選択した座標参照系の座標単位です。

### 5. Nodata 補間を指定

**Nodata値の補間を行う（処理に時間がかかります）** にチェックを入れると、TIN 補間後にラスター上の Nodata を近傍点の値へ補間します。

- チェックあり：グランドデータなど、空白領域があるデータ向け
- チェックなし：最近傍補間を使用

補間処理には時間がかかる場合があります。

### 6. 座標参照系を指定

「座標参照系」でデータの座標参照系を指定します。初期値は `EPSG:6677`（JGD2011 / Japan Plane Rectangular CS IX）です。

座標参照系は入力データに合った値を選択してください。

### 7. 出力ファイルを指定

「出力ファイル」で、生成する GeoTIFF の保存場所とファイル名を指定します。

拡張子は `.tif` または `.tiff` を使用してください。

### 8. 変換を実行

| ボタン | 機能 |
|---|---|
| **変換開始** | 選択したファイルを DEM に変換し、一つの GeoTIFF に結合して保存 |
| **閉じる** | プラグインのダイアログを閉じる |

変換中は進捗ダイアログが表示されます。「キャンセル」を押すと処理を中止できます。変換完了後は、指定した出力ファイルがラスタレイヤーとして自動的に QGIS に追加されます。

## サンプルデータ

動作確認用の ZIP サンプルは `plugins/sample/` に保存されています。

## エラーが発生する主な場合

- 変換するファイルを選択していない
- 出力ファイルを指定していない
- 座標参照系が無効
- 出力フォルダーが存在しない、または書き込みできない
- 指定した列に数値以外のデータが含まれる
- 有効な座標点が 3 点未満
- X または Y の座標範囲がない
- 出力グリッド数が1億を超える

## 補足

- 入力と出力では座標参照系の変換は行わず、指定した座標参照系を結果へ設定します。
- グリッドの位置や補間方法が異なるため、ほかのソフトウェアで作成した DEM と値や形状が異なる場合があります。
